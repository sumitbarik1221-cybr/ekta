# EKTA — One India. Endless Journeys.

EKTA is a travel discovery and planning web app focused on exploring India. It brings destination information, travel tools, and trip planning together in one place.

## Features

- Destination discovery and travel information
- Interactive map and nearby discovery
- AI travel assistant
- Day-by-day itinerary builder with budget and travel preferences
- Weather, accessibility, safety, and local-culture guidance
- Saved places and trips
- Email sign-up, verification, sign-in, and password reset through Supabase Auth

Some features rely on external API keys and may be unavailable until those keys are configured.

## Tech stack

- React
- Vite
- Supabase Auth, database, and Edge Functions
- Netlify Functions for the `/api/*` backend routes
